Se dispone de un sistema compuesto por 1 central y 2 procesos periféricos, que se
comunican continuamente. Se requiere modelar su funcionamiento considerando las
siguientes condiciones:
- La central siempre comienza su ejecución tomando una señal del proceso 1; luego
toma aleatoriamente señales de cualquiera de los dos indefinidamente. Al recibir una
señal de proceso 2, recibe señales del mismo proceso durante 3 minutos.
- Los procesos periféricos envían señales continuamente a la central. La señal del
proceso 1 será considerada vieja (se deshecha) si en 2 minutos no fue recibida. Si la
señal del proceso 2 no puede ser recibida inmediatamente, entonces espera 1 minuto y
vuelve a mandarla (no se deshecha).

Central recibe de P1 -> toma de cualquier P
Central recibe de P2 -> toma de P2 durante 3 mins
Si la señal de P1 tarda 2 mins en recibirse se desecha
Si la señal de P2 no se recibe de inmediato se espera 1 min y se reenvia

	task Central is
	    entry señalP1(señal: IN texto);
	    entry señalP2(señal: IN texto);
	    entry aviso;
	end central;
	
	task P1;
	task body P1 is
	    señal: texto; 
	begin
	    Loop
	        señal = crear();
	        select
	            central.señalP1(señal);
	        or delay 120
	            null;
	        end select
	    end loop
	end P1;
	
	task P2;
	task body P2 is
	    señal: texto;
	begin   
	    señal = crear();
	    Loop
	        select
	            central.señalP2(señal);
	            señal = crear();
	        else
	            delay(60);
	        end select;
	    end Loop;
	end P2;
	
	task timer is
	    entry aviso;
	end timer;
	task body timer is
	begin
	    Loop
	        accept aviso;
	        delay 180
	        central.aviso;
	    end Loop;
	end timer;
	
	task body central is
	    s: texto;
	    seguir: boolean := false;
	begin
	    accept señalP1(s: IN texto);
	    Loop
	        select
	            accept señalP1(s: IN texto);
	        or
	            accept señalP2(s: IN texto);
	            timer.aviso;
	            seguir = true;
	            while(seguir) Loop
	                select
	                    accept señalP2(s: IN texto);
	                or
	                    accept aviso; 
	                        seguir:= false;
	                end select;
	            end loop;
	        end select;
	    end Loop
	end central;
