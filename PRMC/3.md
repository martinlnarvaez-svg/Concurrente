Implemente una solución para el siguiente problema. Se debe simular el uso de una máquina expendedora de gaseosas con capacidad para 100 latas por parte de U usuarios. Además, existe un repositor encargado de reponer las latas de la máquina. Los usuarios usan la máquina según el orden de llegada. Cuando les toca usarla, sacan una lata y luego se retiran. En el caso de que la máquina se quede sin latas, entonces le debe avisar al repositor para que cargue nuevamente la máquina en forma completa. Luego de la recarga, saca una botella y se retira. <br>Nota: maximizar la concurrencia; mientras se reponen las latas se debe permitir que otros usuarios puedan agregarse a la fila.
~~~
int latas = ...;
sem sin latas = 0;
sem pasar[U] = (*,0);
cola c;
sem mutexCola = 1;
boolean libre = true;
sem hayLatas = 0;

process usuario[id: 0..U-1]{
	P(mutexCola);
	if(not libre){
		c.push(id);
		V(mutexCola);
		P(pasar[id]);
	}
	else{
		libre = false;
		V(mutexCola);
	}
	
	if(latas == 0){
		V(sinLatas);
		P(hayLatas);
	}
	tomarLata();
	latas--;
	P(mutexCola);
	if(not c.isEmpty()){
		V(pasar[c.pop()]);
	}
	else{
		libre = true;
	}
	V(mutexCola);
}

process repositor{
	while(true){
		P(sinLatas);
		latas = 100;
		latas--;
		V(hayLatas);
	}
}
