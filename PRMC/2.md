Implemente una solución para el siguiente problema. Un sistema debe validar un conjunto de 10000 transacciones que se encuentran disponibles en una estructura de datos. Para ello, el sistema dispone de 7 workers, los cuales trabajan colaborativamente validando de a 1 transacción por vez cada uno. Cada validación puede tomar un tiempo diferente y para realizarla los workers disponen de la función Validar(t), la cual retorna como resultado un número entero entre 0 al 9. Al finalizar el procesamiento, el último worker en terminar debe informar la cantidad de transacciones por cada resultado de la función de validación. <br>Nota: maximizar la concurrencia.
~~~

cola transacciones;
sem mutexCola = 1;
int resultados[10] = (*,0);
sem mutexRes[10] = 1;
int terminados = 0;
sem barrera = 1;


process Worker[id: 0..6]{
	transaccion t;
	int res;
	resLocal[10];
	
	P(mutexCola);
	while(not transacciones.isEmpty()){
		t = transacciones.pop();
		V(mutexCola);
		res = Validar(t);
		resLocal[res]++;
		P(mutexCola);
	}
	for(int i=0; i<10; i++){
		P(mutexRes[i]);
		resultados[i] += resLocal[i]:
		V(mutexRes[i];)
	}
	V(mutexCola);
	P(barrera);
	terminados++;
	if(terminados == 7){
		informarResultados(resultados);
	}
	V(barrera);
}
