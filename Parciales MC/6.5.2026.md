1) SEMAFOROS. Se debe simular una carrera de F1, cuando los 22 autos estan ubicados en la grilla, el comisario deportivo larga la carrera. Cada auto da 50 vueltas al circuito, y al terminar
debe esperar a que el comisario deportivo revise el auto (de acuerdo con el orden en que terminaron) para determinar si todo esta correcto, y si es asi le indique el puesto en el que termino,
o en caso contrario que quedo descalificado. Nota: Suponga que existen las funciones UBICARSE() y DAR_VUELTA() que simulan cuando un auto se ubica en la grilla y cuando da una vuelta al 
circuito respectivamente; suponga que existe una funcion REVISAR(id_auto) que simula que el comisario deportivo revisa el auto id_auto;

	sem largar = 0;
	sem barrera[22] = (*,0);
	Cola terminados;
	sem mutexCola = 1;
	sem termine = 0;
	int puestos[22];
	sem espera[22] = (*,0);
	
	process auto(id: 0..22-1){
	    int enPosicion = 0;
	    UBICARSE();
	    enPosicion++;
	    if(enPosicion == 22) V(largar);
	    P(barrera[id]);
	    for(int i=0; i<50; i++) DAR_VUELTA();
	    P(mutexCola)
	    terminados.push(id);
	    V(mutexCola);
	    V(termine);
	    P(espera[id]);
	    int puesto = puestos[id];
	}
	
	process comisario{
	    int descalificados = 0;
	    int puesto = 1;
	    P(largar);
	    for(int i=0; i<22; i++){
	        V(barrera[i]);
	    }
	    for(i=0; i<22; i++){
	        P(termine);
	        P(mutexCola);
	        int idAux = terminados.pop;
	        V(mutexCola);
	        boolean ok = REVISAR(idAux);
	        if(ok){
	            puestos[idAux] = puesto - descalificados;
	            puesto++;
	        }
	        else{
	            puestos[idAux] = -1; //DESCALIFICADO
	            descalificados++;
	        }
	        V(espera[idAux]);
	    }
	}




2) Resolver con MONITORES el siguiente problema. La dia tiene 3 circuitos diferentes para probar 50 auts de las categorias F1 y F2 (22 de F1 y 28 de F2). Cada auto conoce en que circuito
debe hacer sus pruebas, cuando lo tiene a su disposicion lo usa durante 3hs. En cada circuito no puede haber mas de un auto a la vez haciendo sus pruebas, y para usarlos tienen prioridad
los de F1 (entre los autos de la misma categoria se respeta el orden de llegada). Nota: maxizimizar la concurrencia; los unicos procesos que se pueden usar son los que representen a los
autos; suponga que existe la funcion USAR() que simula el uso del circuiro por parte de un auto

	process auto(id:0..49){
	    Tipo tipo;    // SE CONOCE
	    int cir;      // SE CONOCE
	    circuito[cir].llegue(tipo);
	    sleep(3hs); //SIMULA QUE SE USA EL CIRCUITO DURANTE 3HS
	    circuito[cir].saliendo();
	}
	
	Monitor circuito(0..2){
	    colaEspecial fila;
	    boolean libre = true;
	    cond esperaF1;
	    cond esperaF2;
	
	    procedure llegue(Tipo in tipo){
	        if(!libre){
	            fila.push(tipo); //SE PUSHEA ORDENADO POR TIPO DE AUTO (F1 PRIMERO F2 DESPUES)
	            if(tipo == F1){
	                wait(esperaF1);
	            }
	            else{
	                wait(esperaF2)
	            }
	        }
	        else{
	            libre = false;
	        }
	    }
	
	    procedure saliendo(){
	        if(fila.isEmpty()){
	            libre = true;
	        }
	        else{
	            Tipo tipo = fila.pop();
	            if(tipo == F1){
	                signal(esperaF1);
	            }
	            else{
	                signal(esperaF2);
	            }
	        }
	    }
