En una empresa de logística de paquetes existe una sala de contenedores donde se preparan las entregas. Cada contenedor puede almacenar un paquete y la sala cuenta con capacidad para N contenedores. Resuelva considerando las siguientes situaciones: <br>a) La empresa cuenta con 2 empleados: un empleado Preparador que se ocupa de preparar los paquetes y dejarlos en los contenedores; un empleado Entregador que se ocupa de tomar los paquetes de los contenedores y realizar las entregas. Tanto el Preparador como el Entregador trabajan de a un paquete por vez. <br>b) Modifique la solución a) para el caso en que haya P empleados Preparadores. <br>c) Modifique la solución a) para el caso en que haya E empleados Entregadores. <br>d) Modifique la solución a) para el caso en que haya P empleados Preparadores y E empleados Entregadores.<br>
a)
~~~
cola c;
sem mutex = 1;
sem trabajar = 0;
sem contenedores = N;

Process Preparador[id: 0..P-1]{
	paquete p;
	
	while(true){
		prepararPaquete(p);
		P(contenedores);
			P(mutex);
				c.push(p);
				cant++;
			V(mutex);
			V(trabajar);
		}
	}
}

Process Entregador[id: 0..E-1]
	while(true){
		P(trabajar);
		P(mutex);
			paquete p = c.pop();
		V(mutex);
		V(contenedores);
		entregarPaquete(P);
	}
}
