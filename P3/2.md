Existen N procesos que deben leer información de una base de datos administrada por un motor que admite un número limitado de consultas simultáneas. <br>a) Analice el problema y defina qué procesos, recursos y monitores/sincronizaciones serán necesarios/convenientes para resolverlo. <br>b) Implemente el acceso a la base de datos por parte de los procesos, sabiendo que el motor de la base de datos puede atender a lo sumo 5 consultas de lectura simultáneas.<br>
a) Seran necesarios el proceso lector y el monitor motor (que va a simular ser un semaforo)<br>
b)
~~~
process lector[0..N-1]{
	motor.acceder();
	//leyendo
	motor.salir();
}

monitor motor{
	cond cola;
	int cant = 5;
	
	procedure acceder(){
		while(cant = 0) wait(cola);
		cant--:
	}
	
	procedure salir(){
		cant++;
		signal(cola);
	}
	
}
~~~
